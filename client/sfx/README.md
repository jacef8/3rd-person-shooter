# Real sound recordings for Deadzone

All of these are **CC0** on Freesound (free for any use, no credit required — we credit them anyway).
Download each one (free Freesound login, then the **Download** button on the page), then upload them all
to this folder's `raw/` subfolder on GitHub. Claude trims, levels and converts them to game files.
